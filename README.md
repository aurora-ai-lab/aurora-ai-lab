> **One-line version:** HosieryLab is a structured hosiery visual library where an image, its metadata, and its reusable prompt layers stay connected.

## Flagship project — HosieryLab

<a href="https://hosierylab.com"><img src="https://github-readme-stats.vercel.app/api/pin/?username=aurora-ai-lab&repo=hosierylab&theme=transparent&hide_border=true&title_color=C42E47&text_color=6F6260&icon_color=D9B68C" alt="HosieryLab repository card" /></a>

HosieryLab turns a vague request like “black tights” into a controlled visual reference:

- **Denier and opacity** — 5D, 15D, 20D, 40D, 60D, 100D and beyond
- **Color and surface** — black, white, ivory, neutrals, matte, satin, gloss
- **Construction** — pantyhose, knee-highs, thigh-highs, welt, toe, heel, knit, pattern
- **Prompt layers** — full-body context plus a focused hosiery specification
- **Website-first access** — images, metadata and prompts are connected through the live catalog for people and tools to reuse

## The workflow

```text
Find a specimen  →  inspect the image  →  copy one prompt layer  →  render  →  compare one variable
```

The system is deliberately split into small decisions. Change the Denier, opacity, color, finish, or construction without losing the rest of the scene.

## For creators and builders

- **Creators:** use the catalog as a visual reference before generating.
- **Prompt engineers:** copy the full-body prompt or the single hosiery layer.
- **MCP users:** use the website as the source for connected image, metadata, and prompt records.
- **Contributors:** report missing constructions, confusing labels, broken links, or useful workflows in [Issues](https://github.com/aurora-ai-lab/hosierylab/issues).
